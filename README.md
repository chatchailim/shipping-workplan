# OPT Shipping Work Plan v2

P0 scaffold for the server-rendered shipping work-plan system. The baseline uses Next.js 15, strict TypeScript, Prisma, PostgreSQL 16, JWT sessions, Vitest, and GitHub Actions.

## Local setup

1. Copy `.env.example` to `.env` and replace all placeholder credentials.
2. Run `docker compose up -d`.
3. Run `npm run db:migrate -- --name init` and `npm run db:seed`.
4. Run `npm run dev`.

Run `npm run check` before every commit. Never commit `.env` or production credentials.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
